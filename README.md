
# 🏡 Haven Syria — منصة وتطبيق عقاري متكامل

منصة عقارية متكاملة ومصممة خصيصاً للسوق العربي، تتكون من تطبيق محمول وواجهة ويب (مبنية بـ **Flutter**) مع نظام خلفي قوي (مبني بـ **Laravel**). تتيح المنصة إدارة العقارات بالكامل وتسهيل التواصل بين الزبائن، أصحاب العقارات، المكاتب العقارية، ومدير النظام.

---

## ✨ المميزات الرئيسية

* **🔐 نظام مصادقة آمن:** تسجيل حساب جديد، تسجيل دخول محمي، تحقق عبر الـ OTP، وإعادة تعيين كلمة المرور.
* **🔍 بحث وفلترة متقدمة:** بحث حر، وفلترة دقيقة حسب السعر، المنطقة، نوع العقار ونوع العرض (إيجار/بيع)، مع خيارات ترتيب حسب الأحدث أو السعر.
* **🏠 تفاصيل العقار الشاملة:** عرض صور متعددة، الموقع الجغرافي، السعر، المساحة، الوصف الدقيق، وبيانات التواصل المباشر.
* **📋 دورة حياة العقار الممنهجة:**
> `طلب جديد` ⟵ `قيد المراجعة` ⟵ `مقبول / مرفوض` ⟵ `نشر العقار`
> *(مع إمكانية تسجيل سبب الرفض وإرسال إشعار تلقائي لصاحب العقار).*


* **❤️ المفضلة وحفظ العقارات:** إمكانية حفظ العقارات المفضلة والرجوع إليها في أي وقت.
* **📞 تواصل مباشر:** اتصال هاتفي فوري أو محادثة مع الجهة المسؤولة عن العقار.
* **🔔 إشعارات فورية:** تنبيه المستخدمين بتغيرات حالة طلباتهم والقرارات المتخذة.

---

## 👥 الأدوار الصلاحيات في النظام
1. **صاحب العقار:** تقديم طلبات إضافة العقارات ومتابعة حالتها لحظياً.
2. **الزبون:** تصفح العقارات، البحث، والاتصال المباشر.

---

## 🎯 فوائد التطبيق

* **للزبون:** توفير الوقت، مقارنة الخيارات بسهولة، والوصول للجهة المسؤولة مباشرة.
* **لصاحب العقار:** إضافة العقارات إلكترونياً، المتابعة اللحظية، ومعرفة أسباب الرفض بدقة إن وجدت.
